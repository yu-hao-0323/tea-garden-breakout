# 茶园突围 · 双生守护

两位真人定制的 Q 版守护者，在茶园中迎战暗影的单人动作小游戏。

- 青锋：玉刃横扫、回风斩、万叶归刃。
- 灵叶：追踪飞叶、闪身回血、青岚结界。
- 两位角色各有待机、跑动、普攻、绝技动作序列，以及冲刺残影和受击反馈。
- 四种独立怪兽造型：枯叶灵、荆棘疾兽、苔岩卫和茶魇；各有不同体型、移动起伏和受击反馈。
- 普攻使用蓄力、出手、收招节奏：青锋基础间隔 0.95 秒，灵叶 0.8 秒；攻速升级后保留最短动作间隔。
- 手机横屏操作；竖屏时阻止操作并暂停战斗。
- 灵露拾取、三选一升级、敌人波次和最终首领。

## 操作

手机：横屏后使用左侧摇杆移动、右侧按钮释放技能。

电脑：WASD / 方向键移动，Q / 空格释放技能一，E 释放技能二，F 开启宝箱或进入附近传送门，Esc 暂停。

竖屏限制通过游戏界面和输入拦截实现。支持全屏方向锁定的浏览器会尝试切换横屏；其他浏览器需要关闭系统方向锁定并手动旋转手机。竖屏后返回横屏时，点击“继续战斗”恢复，避免意外受击。

## 本地运行

纯静态网页，无安装依赖。

```sh
python3 -m http.server 8080 --directory dist
```

访问 `http://localhost:8080`。角色资源使用本地路径加载，需通过 HTTP 服务运行。

## 检查

Node.js 22 或更高版本：

```sh
npm run check
npm test
```

检查包括角色技能、伤害时机、动作切换、升级暂停、胜负结算、横屏条件及资源路径；不包含真实手机浏览器测试。

## GitHub Pages

将项目推送至 GitHub 仓库的 `main` 分支，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。运行 `.github/workflows/pages.yml`；它会检查游戏并将 `dist/` 发布到 Pages，成功地址由工作流的 deployment 输出提供。

工作流配置参考：[GitHub 官方 Pages 工作流文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。所有游戏资源使用相对地址，支持仓库子路径。

`.openai/hosting.json` 是原有 Sites 项目的身份配置；游戏与 Pages 工作流不依赖它，Pages 只上传 `dist/`。

## 资源

`dist/assets/` 中包含定制角色、茶园背景和两张 4×4 动作图集。动作图集在运行时进行透明合成并按实际画面边界取帧，保留了抬剑动作的完整武器。

## 游戏大厅与触控

根路径是游戏大厅；茶园突围入口为 `play.html`。以后新增游戏时，在 `dist/index.html` 的 games 区域添加对应的游戏卡片和相对路径即可。大厅支持横竖屏浏览，茶园游戏保持手机横屏要求。

触屏左下方 44% 宽、62% 高的区域支持浮动摇杆。按下定位，超过摇杆半径时底座跟随且保持在区域内；松手、取消、暂停、旋转屏幕时清零移动。右侧技能区独立支持同时操作。

`monsters.png` 是带真实透明通道的四种怪兽图集。`monsters.js` 按实际轮廓裁取素材，保留首领的枝角冠，避免相邻格子的爪子混入；受击颜色在载入时缓存，战斗中不重复处理图片像素。


## 2.0：无尽守望与闯关征途

游戏大厅入口不变。进入茶园后先选模式，再选守护者。

- **闯关**：五关；前四关有限敌潮全部清除后，恢复 18% 最大生命并重置技能冷却，生成宝箱。宝箱随机三选一；领奖后出现分支传送门，靠近后按 F 或触屏按钮进入。第五关月蚀遗庭为终点首领战，首领半血后增加有预警的落火攻击；领取终章宝箱后结算。
- **无尽**：取消 90 秒截止。敌人生命、伤害、移动速度和刷新压力随时间增长，每 30 秒出现精英，定期生成首领；击败后可开箱继续。敌人数量有上限，难度不封顶。
- **地点**：青山茶园、风啸竹海、寒潭雪境、赤焰古祠、月蚀遗庭。竹海侧重疾兽，寒潭霜灵会发射冰弹，古祠有强化岩卫和延迟落火，各场景有独立背景与怪物色调。
- **武器**：本命武器、惊雷枪（贯穿）、霜羽扇（散射减速）、赤焰轮（周身范围伤害）。获得武器会替换普攻，角色技能保留。武器最高 5 级。
- **法宝**：甘霖铃定时回血、流光珠近身脉冲、玄玉印减伤，最高 3 级。角色强化卡和武器锻造卡也会在宝箱出现。
- **本局成长**：升级、装备、法宝和路线都在本局内保留；失败或重开会重置。此版没有跨局存档。
- **触控**：保留浮动摇杆和横屏要求；开箱时暂停。传送门需要移动接近后主动确认，不会意外踩中就传送。左上角装备按钮可暂停查看当前配装。

`expedition.js` 在原战斗引擎上增加关卡与装备状态。`journey-view.js` 绘制宝箱、传送门和危险区域。`realms.png` 为四场景图集，`chest.png` 为宝箱开合图集。

验证包括两位角色的五关流程、宝箱与传送防重入、无尽超过三分钟、贯穿/散射/范围武器、法宝效果、地点敌人投射和落火预警。
